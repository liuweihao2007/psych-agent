# 数据处理说明

## 数据来源
使用自行构造的心理支持问答模拟数据集，以及公开心理援助指南。

## 处理方法
1. **清洗**：去除空行、多余空格，合并为 `knowledge` 字段。
2. **过滤**：去除长度短于 50 字符的无效文本。
3. **存储**：清洗后保存为 `data/processed/knowledge.csv`。
4. **检索构建**：将数据转换为 JSON 结构存入 `chroma_db/data.json`，供 `search_knowledge` 工具进行关键词检索。

## 实际用途
为 Agent 提供本地知识库，当用户询问相关心理知识时，通过检索返回匹配的建议，避免大模型幻觉。
